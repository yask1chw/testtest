# Хелп18 — сборка для REG.RU

[Скачать готовый ZIP](help18-regru-production.zip?raw=true)

На сайте доступен только звонок: +7 (965) 840-70-03. Формы и отправка заявок удалены.

Распакуйте содержимое ZIP в корень сайта на REG.RU, без дополнительной папки. Не пропустите скрытый файл `.htaccess`. В архиве 18 публичных статических страниц с полным HTML, assets, robots.txt, sitemap.xml и urls-for-indexing.txt.

Проверены сборка, lint, TypeScript, 18 ответов HTTP 200, редиректы и 404 на Apache; работа без JavaScript, гидратация, FAQ, меню и прокрутка. Внешние изображения и шрифты сохранены; их доступность из среды проверки ограничена сетевой политикой. Коды Яндекс.Вебмастера и номер Метрики пользователем не предоставлены.
